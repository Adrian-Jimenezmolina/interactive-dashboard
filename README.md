## Weekly Task Goals
This feature calculates a user’s task targets based on daily goals and weekly bonuses.  
The user enters their name, a daily task goal, and any bonus tasks for the week.  
The calculator multiplies the daily goal by 5 (workdays) and then adds the bonus tasks to produce a total weekly target.  
Results are displayed dynamically on the page without a full page reload.
